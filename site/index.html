    Why the June circuit failed

    In June every ancilla measurement was followed by a Qiskit reset. On IQM hardware a reset is itself a measurement followed by a conditional π pulse, and placed between the readouts it kept them from running in parallel. One round took — µs, and the data qubits waited through it without dynamical decoupling. By round 3 the logical bit was gone: even after decoding, the result is a coin flip.

    The current circuit reads all ancillas out at once and does not reset them; each check compares an ancilla with its outcome two rounds earlier instead (Gehér et al.). IQM's dynamical decoupling protects the idle qubits, and a round takes — µs.

        How these numbers were made

        Each run stores a logical bit in a d = 3 rotated surface code (17 qubits), repeats the stabilizer checks for a given number of rounds, reads the bit out and decodes it with minimum-weight matching built from IQM's calibration data. Memory Z and memory X test the two kinds of logical error. Before each main run the simulator's prediction was pushed to GitHub, so a wrong prediction stays visible, as with the decoupling result above.

        Code, configurations and every archived result: github.com/kazulak/JunctionHackathon. The June 7 curve is the hackathon's own hardware run; the submission is frozen under the tag junction-quantum-hackathon-final-2026, and everything else on this page came after the event.

        Every number on this page is read from data/, which scripts/build_site_data.py builds from the archived results in the repository; the test suite fails if the two disagree.
